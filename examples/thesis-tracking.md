Example structure - values omitted.

## User Request

```text
Use YouRich to show what changed in NVIDIA since my previous analysis.
```

## Workflow Used

- Load the latest local research snapshot.
- Build a current deterministic research snapshot.
- Compare financial, valuation, risk, peer, earnings, and event context.
- Render a compact change report.

## Representative Output

```text
Since Previous Analysis
Key Changes
New Material Events
Thesis
Overall Change
Watch Variables
Data Basis
```

## Why This Is Useful

The result uses stored local snapshots instead of relying on conversation memory
to infer what was known previously.
