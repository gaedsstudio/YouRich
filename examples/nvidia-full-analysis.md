```text

```

## Workflow Used

- Fetch SEC financials.
- Gather filing evidence.
- Run valuation, financial quality, risk, peer, earnings, and event checks.
- Render the structured report.

## Why This Is Useful

The output separates deterministic financial metrics from qualitative
interpretation, keeps SEC basis metadata visible, and preserves warnings when
evidence is incomplete.
